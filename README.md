## 🚀 Selected Projects

### [BusTub — Relational Database Internals](https://erwinzhou.github.io/projects/bustub-dbms)

Built core internals of a disk-oriented relational DBMS in C++: a buffer pool manager, B+ tree indexing, a transaction-aware query execution engine, and optimizer rewrite rules. **Top 5% on the performance leaderboard.**

### [Suffix Speculative Decoding for LLM Serving](https://erwinzhou.github.io/projects/suffix-speculative-decoding)

Integrated suffix-based speculative decoding into the Hugging Face generation stack, reusing repeated context patterns without a separate draft model for **1.74× faster decoding**. Designed a unified verification interface for suffix and tree-based speculation, achieving **1.30× speedup** on tree-spec workloads. [Code →](https://github.com/ErwinZhou/transformers)

### [Distributed Scholarly Search Engine](https://erwinzhou.github.io/projects/distributed-scholarly-search)

Built a microservices search engine on a 3-node GCP cluster with Docker, Kafka, MapReduce, and Terraform. Indexed **10K+ IEEE abstracts** and made queries **37% faster** by conditionally skipping MapReduce jobs.
